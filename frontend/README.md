# Collaborator Task Platform

A comprehensive full-stack web application for task management and performance tracking, designed and developed by **Yassine Bassoumi**.

## Overview

The Collaborator Task Platform enables managers to efficiently assign and track tasks for collaborators while providing real-time performance insights and notifications.

## Features

### For Managers
- 📋 Create and assign tasks with deadlines and priorities
- 📊 Monitor task progress and completion status
- ⭐ Evaluate collaborator performance (punctuality, quality)
- 📈 View comprehensive dashboards and reports
- 🔔 Receive real-time notifications

### For Collaborators
- ✅ View assigned tasks with detailed information
- 🎯 Confirm task completion with optional evidence
- 📈 Track personal performance metrics
- 📊 Access task history and statistics
- 🔔 Get instant notifications for new assignments

## Tech Stack

- **Frontend**: React.js, Tailwind CSS, Shadcn/UI Components
- **Backend**: FastAPI (Python), JWT Authentication
- **Database**: MongoDB Atlas
- **Additional**: Axios, React Router, Chart.js

## Security & Features

- 🔐 Secure JWT-based authentication with SHA256+salt hashing
- 🎛️ Role-based access control (Manager/Collaborator)
- 📱 Responsive design for all devices
- ⚡ Real-time updates and notifications
- 🎨 Modern UI with consistent design system
